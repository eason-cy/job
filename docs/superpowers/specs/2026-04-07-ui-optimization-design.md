# UI 优化设计规范

**日期**: 2026-04-07
**项目**: 校招投递记录管理系统
**方向**: 极简纯净 + 灵动活泼

---

## 一、设计方向

### 风格定位
- **参考**: Apple / Arc Browser 风格
- **关键词**: 克制优雅、柔和圆润、流畅动效、微妙反馈
- **策略**: 渐进式优化，在现有基础上迭代改进

### 核心原则
1. **留白即设计** — 增加间距，让内容呼吸
2. **圆润友好** — 更大的圆角，更柔和的视觉
3. **动效愉悦** — 弹性动画带来生命感
4. **层次分明** — 多层阴影拉开空间感

---

## 二、设计系统

### 2.1 圆角系统

| 用途 | 当前值 | 优化值 |
|------|--------|--------|
| 小元素（标签、徽章） | 4px | 8px |
| 按钮、输入框 | 8px | 12px |
| 卡片、菜单项 | 12px | 18px |
| 面板、弹窗 | 16px | 24px |

### 2.2 间距系统

基础间距增加 25%：

```
--space-1: 4px   → 4px
--space-2: 8px   → 8px
--space-3: 12px  → 12px
--space-4: 16px  → 16px
--space-5: 20px  → 20px
--space-6: 24px  → 24px
--space-8: 32px  → 32px
--space-10: 40px → 40px
--space-12: 48px → 48px
--space-16: 64px → 56px
```

卡片内边距：16px → 20px
面板内边距：18px → 24px
主内容区边距：32px → 40px

### 2.3 阴影系统

**三层柔和阴影**：
```css
/* 卡片默认 */
--shadow-card: 0 1px 3px rgba(0,0,0,0.06), 0 4px 12px rgba(0,0,0,0.04);

/* 卡片悬浮 */
--shadow-card-hover: 0 4px 16px rgba(59,130,246,0.12), 0 8px 32px rgba(59,130,246,0.08);

/* 弹窗层级 */
--shadow-modal: 0 12px 40px rgba(0,0,0,0.12), 0 4px 12px rgba(0,0,0,0.04);
```

**蓝色光晕**：
```css
/* 强调元素 */
--glow-primary: 0 0 20px rgba(59,130,246,0.2), 0 0 40px rgba(96,165,250,0.1);
```

### 2.4 色彩微调

保持 Royal Blue 主色系，微调渐变：
- 主色从 `#2563eb` 调整为 `#3b82f6`（更柔和）
- 渐变从 `#1e40af → #3b82f6` 调整为 `#3b82f6 → #60a5fa`

## 三、动效系统

### 3.1 缓动曲线

| 场景 | 曲线 | 时长 |
|------|------|------|
| 入场动画 | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 300-400ms |
| 交互动画 | `cubic-bezier(0.4, 0, 0.2, 1)` | 150-250ms |
| 退场动画 | `cubic-bezier(0.4, 0, 1, 1)` | 150-200ms |

### 3.2 具体动效

**按钮点击**：
- 缩放至 0.97
- 时长 150ms
- 弹性曲线

**卡片悬浮**：
- 上移 4px
- 阴影增强
- 时长 300ms

**菜单项 hover**：
- 上移 2px
- 背景色变化
- 时长 200ms

**页面入场**：
- 元素从下方淡入（translateY 16px → 0）
- 交错延迟 80ms
- 时长 400ms

**状态标签切换**：
- 缩放 1.05 弹性反馈
- 颜色过渡
- 时长 200ms
